# 原译 · RTranslate

用你已有的桌面 Agent 把英文科研论文译成学术中文。原译在本机解析 PDF、识别英文扫描页和图中文字、保护公式并重新排版。语言翻译由宿主 Agent 执行。Codex 的独立批次默认使用已登录 CLI 的缺省模型，可指定模型 ID。也可以单独连接 OpenAI 兼容的 Chat Completions API。支持 Apple 芯片及 Intel 的 macOS、Windows x64。无需安装本地大语言模型。Agent 或 API 服务的额度和费用按所用账户计算。

## 一句话安装

在能运行本机命令的 **Codex、DeepSeek Harness 或 WorkBuddy** 中发送：

> 请从 https://github.com/irave7/RTranslate 安装「原译」到我当前使用的 Agent，按仓库的 INSTALL.md 选择 macOS 或 Windows 安装器，完成后检查能否调用。

然后提供论文并说「用原译翻译这篇论文」。Codex 也可以用 `$rtranslate` 指定技能。首次提示三种输出，默认只生成中文版。也可以选择仅中英对照，或两份都生成。选择会保存在这台电脑上。之后说「这次给我双语版」可以临时覆盖，说「以后两份都要」可以更改默认。[安装操作与宿主目录](INSTALL.md) · [GitHub Releases](https://github.com/irave7/RTranslate/releases/latest)

## 论文如何处理

- PDFMathTranslate-next 和 BabelDOC 负责分段、公式与版面。RetainPDF 的续句规则在跨页或跨栏时提供相邻原文。译文在原文本块内排版，段内可换行，以容纳完整中文。
- 本机 OCR 为英文扫描页建立文字层，并从图片中提取英文标签。流程图中的条件、否定和组别会和图注一起核对。遇到背景复杂、分辨率过低的图片，部分标签可能保留英文。
- 只生成选定的 PDF。双语版逐页并排呈现，在左侧保留原稿。可以指定自己的英中术语表，或只校订某页的一段，用已有译文重新排版。
- 独立工作会话每批只读本次翻译包，由主会话传递路径和完成状态。包内保留整段原文、必要的续句及命中术语，共用提示只传一份。已提交批次可在中断后复用。使用普通连续聊天时，聊天历史的计量由宿主决定。
- 使用独立 API 时，每次请求仅含当前任务。密钥通过环境变量传入，论文文件与排版留在电脑，待译文字会发送给所选服务商。[独立 API 用法](API.md)

## 实测

同一篇 14 页开放获取临床论文包含表格、跨页正文及两幅流程图。在上一版实测的 169 个请求上回放，新版紧凑格式的待译输入约为 **26,907 token**，前一版为 44,986，原生消息为 163,305。相较前一版再降 **40.2%**。这是用 o200k_base 计算的数据传输量，宿主系统提示、输出和推理另计。阅读样例中的表 3–5 共核对 235 项数值，图内 40 个标签已在先前双语测试中写回。[论文、核验方式与限制](examples/clinical-paper/README.md)
