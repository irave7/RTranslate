# Installing RTranslate for the current user

For a request to install 原译 / RTranslate, follow INSTALL.md. Choose the installer for the actual operating system and the requested host. Use the published release archive with its SHA-256 manifest. The installable skill includes the engine; the source subdirectory skills/rtranslate on its own is incomplete. After installation, run the installed launcher with preferences and report where it was installed. For translation tasks use the installed skill.
